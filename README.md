# 📇 Contact Management Application

A full-stack Contact Management App built using **React, FastAPI, and MongoDB**.  
It allows users to create, view, update, and delete contacts with persistent storage.

---

## 🚀 Tech Stack
- Frontend: React.js  
- Backend: FastAPI (Python)  
- Database: MongoDB  

---

## ✨ Features
- Create, Read, Update, Delete contacts  
- Data validation  
- Persistent storage  
- Toast notifications  

---

## ⚙️ Setup

### Backend
cd backend  
pip install -r requirements.txt  
uvicorn main:app --reload  

### Frontend
npm install  
npm run dev  

---

## 🧑‍💻 Usage
- Add new contact  
- Edit or delete contacts  
- Data persists after refresh
